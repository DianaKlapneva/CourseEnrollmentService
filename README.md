# CourseEnrollmentService
Репозиторий с микросервисом (с использованием GraphQL) для управления онлайн-курсами и записью студентов.
## Архитектура
- API Gateway (порт 5000)
- Students Service (порт 5001) - управление студентами
- Courses Service (порт 5002) - управление курсами  
- Enrollments Service (порт 5003) - управление записями
- PostgreSQL 15 (общая база данных)

## Порядок действий при запуске проекта
1. Необходимые зависимости:  flask flask_cors graphene psycopg2-binary
2. База данных education_db и таблицы (SQL в pgAdmin)
3. Запускаем сервисы в 4 отдельных терминалах
4. Открываем файл frontend.html в браузере

## Реализация CRUD
Реализовано создание, чтение, обновление, удаление для всех трех сущностей
Запросы можно делать как через визуальный интерфейс, так и через командную строку при необходимости
